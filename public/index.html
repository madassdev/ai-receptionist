How it's built

The AI can't overbook

Every booking claims each half-hour it covers for one technician, and the database rejects any overlapping claim. It holds even if many requests or servers race for the same time.

It only offers real times

The AI calls the booking system for availability and must use a time it returned. Opening hours, lead time and job length are enforced in code, not left to the AI.

Customers' bookings stay private

Changing or cancelling needs the reference code and the last four digits of the phone number. The calendar here masks names and numbers.

Spend is capped

Each chat passes a quick proof-of-work check, has a message limit, and the whole demo has a daily budget and a switch to turn the AI off.
